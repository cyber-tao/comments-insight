## Store Listing

**Extension Name**
Comments Insight: Find User Needs in Comments Across Sites

<!-- Localized item titles come from `extensionName` in `public/_locales/*/messages.json` (max 75 chars). -->

**Short Description**
Collect comments from social media posts and use your configured AI model to analyze them.

<!-- Matches `extensionDescription` in `public/_locales/en/messages.json` (90/132 chars). -->

**Detailed Description**

```text
What does your audience care about most? Which questions come up again and again? Comments Insight turns comments and replies into searchable records, then uses your configured AI service to analyze the discussion and generate reports you can save and share—including standard Markdown documents and polished web reports (optional).

💬 Collect Discussions
Extract comments and multi-level replies on supported post pages. Built-in rules scroll to load comments and expand replies on applicable pages.

Includes built-in comment extraction rules for several major platforms. You can also add or edit extraction rules in the extension settings to collect comments on additional platforms and adapt to different page layouts.

✦ Analyze Topics and Sentiment
Summarize recurring questions, audience feedback, and overall sentiment, pairing top-liked comments with representative replies for context. Customize prompts to organize the analysis around the questions you care about.

▣ Generate and Export Reports
Read structured analysis or generate web reports with charts and key takeaways. View them in a new tab or export them as standalone HTML files. Export analysis results as Markdown and raw comments as CSV. Search comments in History and sort by time, likes, or reply count.

Use Cases
• Content creators finding topic ideas from recurring questions.
• Marketing teams organizing launch feedback and common concerns.
• Researchers summarizing discussion themes while keeping raw records for review.

Quick Start
Open a supported post and click "Extract Comments" from the extension popup. To use AI analysis, configure a Chat Completions-compatible API endpoint, model, and required credentials in Options, then click "Analyze Comments". The interface is available in Simplified Chinese, Traditional Chinese, English, Japanese, Korean, French, Portuguese (Portugal), and Spanish.

Data Handling
Settings, collected records, and reports are stored in your browser. When you run an AI feature, the extension sends the required webpage or comment data and your configured API credentials directly to the service you selected, which processes the request under its own privacy policy.

Source Code & Feedback
https://github.com/cyber-tao/comments-insight
```

Incluye reglas de extracción de comentarios para varias plataformas populares. También puedes añadir o editar reglas de extracción en la configuración de la extensión para recopilar comentarios en más plataformas y adaptarte a distintos diseños de página.

✦ Analizar temas y sentimiento
Resume las preguntas recurrentes, las opiniones de la audiencia y el sentimiento general, combinando los comentarios con más «me gusta» y respuestas representativas para entender el contexto de la conversación. Personaliza las instrucciones para organizar el análisis según las preguntas que te interesen.

▣ Generar y exportar informes
Lee un análisis estructurado o genera informes web con gráficos y conclusiones clave. Puedes verlos en una pestaña nueva o exportarlos como archivos HTML independientes. Los resultados del análisis se pueden exportar como Markdown y los comentarios originales como CSV. Busca comentarios en el historial y ordénalos por fecha, número de «me gusta» o número de respuestas.

Casos de uso
• Creadores de contenido que buscan ideas de temas a partir de preguntas frecuentes.
• Equipos de marketing que organizan comentarios de lanzamientos y dudas habituales.
• Investigadores que resumen temas de debate conservando los registros originales para su revisión.

Inicio rápido
Abre una publicación compatible y haz clic en «Extraer comentarios» en la ventana emergente de la extensión. Para usar el análisis con IA, configura en las opciones un endpoint de API compatible con Chat Completions, el modelo y las credenciales necesarias, y luego haz clic en «Analizar comentarios». La interfaz está disponible en chino simplificado, chino tradicional, inglés, japonés, coreano, francés, portugués (Portugal) y español.

Tratamiento de datos
La configuración, los registros recopilados y los informes se guardan en tu navegador. Al ejecutar una función de IA, la extensión envía los datos necesarios de la página web o de los comentarios y las credenciales de API configuradas directamente al servicio que hayas elegido, el cual procesa la solicitud conforme a su propia política de privacidad.

## Permissions Justification

| Permission                  | Type             | Justification                                                                                                                                                                                                                                                                                                                                                |
| --------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `storage`                   | permissions      | Stores user preferences, encrypted AI API credentials, custom/overridden crawling rules, task recovery state, selector validation cache, token counters, and diagnostic logs locally in the browser.                                                                                                                                                         |
| `unlimitedStorage`          | permissions      | Stores user-extracted comment trees, analysis markdown, and generated HTML reports in local IndexedDB without hitting small extension storage limits on large threads.                                                                                                                                                                                       |
| `tabs`                      | permissions      | Reads the active tab's URL and title when the popup opens, monitors tab navigation or closure to abort stale extraction tasks safely, and opens Options, History, and Logs pages (including notification deep links).                                                                                                                                        |
| `scripting`                 | permissions      | Programmatically injects the self-contained extraction script on demand into the target tab only when the user explicitly starts comment extraction, AI rule generation, or selector testing. No static content script runs passively on pages.                                                                                                              |
| `notifications`             | permissions      | Displays desktop notifications when user-initiated background extraction, rule generation, or AI analysis tasks complete or fail, allowing one-click navigation to the saved result.                                                                                                                                                                         |
| `http://*/*`, `https://*/*` | host_permissions | Required for two core user-requested capabilities: (1) on-demand comment extraction and AI rule discovery on arbitrary websites chosen by the user, and (2) sending AI requests directly from the extension to the user's configured AI provider endpoint (remote endpoints enforce HTTPS; plain HTTP is permitted only for loopback development endpoints). |
